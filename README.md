# سایت کلینیک پزشکی ورزشی المپیک

راهنمای کامل راه‌اندازی در فایل DEPLOY-GUIDE.md موجود است.

## اجرای محلی (روی کامپیوتر خودتان، برای تست)
1. Node.js نسخه ۱۸ به بالا نصب کنید: https://nodejs.org
2. در همین پوشه ترمینال باز کنید و بنویسید:
   npm install
3. فایل .env.example را کپی کنید و اسمش را .env بگذارید، سپس مقادیر داخلش را عوض کنید.
4. اجرا کنید:
   npm start
5. سایت: http://localhost:3000
   پنل مدیریت: http://localhost:3000/admin
